# Mechanical Engineering Toolbox

A Python desktop application that provides a collection of 28 engineering calculators and interactive visualizations for common mechanical engineering problems. The project was developed to automate engineering calculations, reinforce engineering concepts, and provide clear graphical representations of physical systems.

## Features

- 28 engineering calculators covering:
  - Mechanics
  - Thermodynamics
  - Strength of Materials
  - Unit Conversions
- Numerical engineering calculations using NumPy
- Engineering data visualization using Matplotlib
- Interactive plots for:
  - Beam Deflection
  - Projectile Motion
  - Free-Fall Analysis
  - Thermodynamic Processes
- User-friendly desktop interface for performing engineering calculations quickly

## Technologies Used

- Python
- NumPy
- Matplotlib

## Purpose

This project was created to strengthen programming skills while applying mechanical engineering principles to real-world computational problems. It demonstrates the use of scientific computing and data visualization to solve and analyze engineering applications.
